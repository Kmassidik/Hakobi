Hakobi 運び

Self-hosted dashboard to manage your DevOps.

Hakobi (運び, “to carry/deliver”) moves your code from commit to production without the YAML and plugin maze. Click to build images, deploy to Docker or Kubernetes, and keep an eye on everything.

Features

One-click image builds, GitHub Actions style
Docker and Kubernetes deploy settings
Auto subdomain provisioning via Cloudflare
Watchdog and health checks
Telemetry and logs in one place
Fully self-hosted, your infra and your data
