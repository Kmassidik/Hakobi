# Asset prompt pack — Hakobi

Original art direction for Hakobi. This covers **Hakobi-specific** assets only.
Docker, Kubernetes, Cloudflare, GitHub, Rust, Nix, PostgreSQL and other brand
marks should be taken from their official brand kits, not generated by AI.

Brand tokens:

```text
deep green   #164f3b
lime         #d8f078
ink          #18211d
surface      #ffffff
line         #dcded7
display      Georgia, "Times New Roman", serif
```

Style: calm Japanese logistics control room. Soft 3D, matte, rounded, friendly
but competent. Not anime, not cyberpunk, not generic SaaS gradients.

## Block 0 — paste first

```text
You are making original 3D artwork for Hakobi, a self-hosted DevOps control
plane. I will send one sheet request at a time.

Rules for every sheet:
- Canvas 1536 x 1024 px, exactly 6 cells in a 3 columns by 2 rows grid.
- Every cell is 512 x 512 and contains one centered object at about 80% of the
  cell, with breathing room and nothing touching the cell edges.
- Read order: left to right, top row first, then bottom row.
- Transparent background (PNG with alpha).
- No text, letters, numbers, labels, borders, grid lines or watermarks.
- Same camera, lighting, scale and palette on every sheet so all assets feel
  like one family.
- Soft 3D, matte plastic and brushed aluminium, rounded edges, slightly
  toy-like but professional. Three-quarter view from front-left and above.
- Soft key light from top-left, gentle contact shadow under each object.
- Shared palette: deep forest green #164f3b, lime #d8f078, warm amber status
  lights, off-white highlights, dark ink details.
- Make everything original. Do not copy any existing product icon or brand.
- If I write "leave empty", keep that cell fully transparent.

Reply "ready" and wait for the first sheet.
```

## Post-processing

```text
ChatGPT PNG
  -> background removal / alpha cutout
  -> slice 512px cells
  -> resize icons to 256x256
  -> export WebP with alpha
  -> place under static/assets/art/
```

Suggested paths:

```text
static/assets/art/3d/source-repo.webp
static/assets/art/3d/build-runner.webp
...
static/assets/art/mascot/hako-idle.webp

static/assets/brand/logo-mark.svg

static/assets/brand/og-hakobi.png
```

QA checklist:

- 16px favicon still readable
- alpha is clean, no white matte
- no text or accidental borders
- same light direction and scale across sheets
- icons remain recognizable at 32px
- dark and light UI backgrounds both tested
- official brand logos are sourced from official kits, not AI
